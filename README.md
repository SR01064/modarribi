# مدرّبي

تطبيق ويب عربي للتدريب اليومي. الواجهة تعمل كصفحة ثابتة، ويمكن تثبيتها على الهاتف بعد نشرها عبر HTTPS.

## الالتزام والتعلّم

خطة اليوم تضع القرآن والقراءة والتمرين والتعلّم كأساسيات وتعيد المهام الأساسية غير المكتملة لليوم التالي. من تبويب التعلّم اختَر السورة والآيات، ثم اكتب اسم الكتاب وحدد الصفحات. بياناتك محفوظة على الجهاز الحالي.

في تبويب الجيم اختَر Push أو Pull أو Legs أو Upper أو Lower أو تمارين الأماميات والخلفيات. الخطط تستخدم أجهزة مثل Lat Pulldown وLeg Press وLeg Curl، مع بدائل منزلية.

## الخلفيات

تبدأ الواجهة بالصورة التي أرفقتها، وتتغير كل ٧٠ ثانية. من الإعدادات تستطيع اختيار حتى ٦ صور إضافية؛ صورك الخاصة تُحفظ على هذا الجهاز فقط. لإظهار صورة على الموقع لكل الأجهزة، أضفها داخل مجلد `assets` في المستودع.

## صوت Fish Audio

لا تضع مفتاح API في ملفات الواجهة أو المستودع. الصوت يمر عبر Cloudflare Worker ويحفظ مفتاح Fish Audio كـ Secret ويقدم نقطة `/api/tts`. التعليقات الجديدة يكتبها Workers AI على الخادم ثم ينطقها Fish Audio؛ لا تحتاج مفتاح Claude. يحتاج Worker binding باسم `AI` في `cloudflare-worker/wrangler.jsonc`.

راجع `FISH-AUDIO-SETUP.md` للتجهيز المحلي وإعداد الخادم. صفحة GitHub Pages لا تشغل الخادم الوسيط.

## إشعارات الهاتف

ثبّت الموقع على الشاشة الرئيسية واسمح بالإشعارات من زر التذكير داخل التطبيق. التذكير اليومي الحالي يعمل أثناء فتح الموقع؛ وصوله بعد إغلاق التطبيق يحتاج إعداد Web Push إضافيًا على الخادم.
