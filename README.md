# مدرّبي

تطبيق ويب عربي للتدريب اليومي. الواجهة تعمل كصفحة ثابتة، ويمكن تثبيتها على الهاتف بعد نشرها عبر HTTPS.

## صوت Fish Audio

لا تضع مفتاح API في ملفات الواجهة أو المستودع. الصوت يحتاج خادم Node.js وسيطًا يحفظ المفتاح في متغيرات بيئة سرية ويقدم نقطة `/api/tts`. ملفات التطبيق الحالية تستخدم `/api/tts` على نفس النطاق؛ ستحتاج نشر خادم `fish-audio-proxy` على استضافة Node.js وضبط واجهة التطبيق لتستخدم عنوانه HTTPS قبل أن يعمل الصوت على الهاتف.

راجع `FISH-AUDIO-SETUP.md` للتجهيز المحلي وإعداد الخادم. نشر GitHub Pages وحده لا يشغل خادم Node.js.
