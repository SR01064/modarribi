# مدرّبي

تطبيق ويب عربي للتدريب اليومي. الواجهة تعمل كصفحة ثابتة على GitHub Pages ويمكن تثبيتها على الهاتف عبر HTTPS.

## صوت Fish Audio

لا تضع مفتاح API في ملفات الواجهة أو المستودع. الصوت يحتاج خادم Node.js وسيطًا يحفظ المفتاح كمتغير سرّي ويقدم نقطة `/api/tts`. ملف `render.yaml` يجهز خدمة الصوت على Render؛ بعد نشرها ضع عنوان الخدمة الكامل مع `/api/tts` في إعدادات الصوت بالتطبيق.

راجع `FISH-AUDIO-SETUP.md` للتجهيز المحلي وإعداد الخادم. نشر GitHub Pages وحده لا يشغل خادم Node.js.
