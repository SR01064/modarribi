# مدرّبي — نسخة اللابتوب

## معاينة وتعديل التطبيق

1. فك ضغط `modarrebi-fish-audio-updated.zip` في مجلد عادي على اللابتوب.
2. افتح `modarrebi-fish-audio.html` في المتصفح للمعاينة، أو افتحه في محرر النصوص لتعديل الواجهة. اترك مجلد `assets` بجانبه حتى تظهر الخلفية.
3. النسخة المنشورة على الهاتف هي `https://sr01064.github.io/modarribi/`. تعديل ملفات اللابتوب وحده لا يغيّر الموقع تلقائيًا؛ عند طلبك تحديثه أرفع التغيير للمستودع وأتحقق من اكتمال نشر GitHub Pages.

## تشغيل صوت Fish Audio على الهاتف

1. ادخل إلى Render، ثم **New → Blueprint**، واربط مستودع `SR01064/modarribi` على الفرع `main`.
2. إعداد `render.yaml` ينشئ خادم الصوت من مجلد `fish-audio-proxy` ويشغل `npm start`.
3. أدخل مفتاح Fish Audio الجديد داخل Render كقيمة سرية لمتغير `FISH_API_KEY` فقط، ثم انتظر حالة **Live**. لا ترسله في المحادثة ولا تضفه لملفات HTML أو GitHub.
4. انسخ عنوان الخدمة من Render، وأضف `/api/tts` في إعدادات الصوت بالتطبيق.
5. معرّف الصوت محفوظ مسبقًا؛ لا تحتاج إلى شراء أو اختيار صوت جديد.

راجع `FISH-AUDIO-SETUP.md` للتفاصيل. مفتاح Fish الذي سبق مشاركته يجب إلغاؤه وإنشاء مفتاح جديد.
